## 决策

1. **pwrite 管线四步**：预分配 → map → 写数据 → 回写元数据（无融合 phase，写路径零融合开销）。
2. **map 只左融合**：插入前查 GLB——逻辑紧贴 && phys 连续 → 不插新记录，直接
   `GLB.length += 新段长`（count 不变、零结构变化）。有界单对操作，与旧 map 内建
   融合的死因（f1d 跨界盲区 / F2 欠载不回收）无交集：不承诺完备（可并残留合法）、
   不删记录（无欠载路径）。分配优先尾巴延展（occupy）→ 左融合条件常真 → 顺序写
   文件记录数 ≈ phys run 数，**不随写次数涨**。
3. **entry[0] 落点（GLB=NONE）刻意跳过跨界左并**：前叶末项可并也不做——跨叶要动
   前叶 count/max + 父 hint 刷新链，不值。f1d 形态残留显式接受，交全量融合兜底。
4. **全量融合 = 激进重建**（低频：close 插桩 + 显式 `merge_extents(fd,start,len)`
   接口，len=0 全文件）：叶链遍历收集全部记录 → 可并对全并 → 满叶（337）重打包 →
   自下而上构建内部节点 → swap 新根 → free 旧树。**失败原子性**：新树建成前旧树
   只读，ENOSPC 失败 = 丢新节点、旧树无损。坍缩前置（extent→direct 判定）与
   "整树节点收集释放轮子"（待办 #3）顺带兑现。
5. **碎片预防优先于碎片收拾**：分配侧（刷回批量连续分配 / delalloc 思路）是第一性
   解；融合（map 左融合 + 激进重建）是兜底。
6. **失败面与回滚（拍板）**：新 map 的失败点仅 split 分配失败 → 水位线预防；实在
   不行 fsck（孤儿交灾难恢复，C 决策）。左融合不新增失败路径，**不做专门回滚机制**
   （length-shrink 类不引入）。写数据失败 = 硬件级 → fsck 范畴。

## 残留融合需求（激进重建的兜底面）

1. entry[0] 跨界对（map 刻意跳过，触发率低——顺序写永不触发）；
2. 随机写 / 空洞回填的中间插入（分配不连续时记录增长）；
3. 历史遗留（旧版 / fsck 后）。
